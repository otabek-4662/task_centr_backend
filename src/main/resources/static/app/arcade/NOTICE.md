# Choyxona Arcade imports

Ten browser games are adapted from [Arcade 100 by Worapon Sangsasri](https://github.com/NnopponS/100-games/tree/96857ba2d7d3fde6a3cc51e5e34ec808bb920165), under the accompanying MIT license.

Choylashamiz uses the upstream games and procedural artwork from that revision. The integrations move inline game scripts into separate files for CSP, use local assets, add Uzbek labels and control instructions, and pass each game's record to the Arcade player. Mini Golf runs with the upstream 2D renderer. Keyboard controls were added to Mini Golf, Reversi and Tower Defense.

## Collection

- **Shafaq poygasi** uses the procedural racer code from [Teb RUN](https://github.com/tebeus/teb-run/tree/bd6c3c8079ebc0b1b1b572a1397013bb5e878f37). The portal build uses a new name, new stage and ending text, and silent radio slots. The engine loops remain under CC0 and the original scores feed the Arcade record.
- **Packabunchas** uses [Mattia Fortunati’s MIT source](https://github.com/MattiaFortunati/packabunchas/tree/fc4e6331fa4b8c17cc341094e9027bccd02f463f). The integration adds keyboard play and a record for the most creatures packed in a session. The accompanying notices cover the ZzFX and ZzFXM audio libraries.
- **Sprout Runner** uses [carlomigueldy’s original MIT game](https://github.com/carlomigueldy/sprout-runner/tree/c0a8445223a57f7daf8e3b521dcfec543796f394). The Arcade version uses a separate script, Uzbek prompts, mouse-accessible controls and a shared record display.
- **Island** uses [StarKnightt’s build and assets](https://github.com/StarKnightt/island/tree/a8dfe84cf3d8a174d452446d50b07276496750fd). See the included credits and notices for models, audio, textures, font and libraries. The two Basis Universal transcoder wrappers are modified to invoke bindings without generating JavaScript at runtime.
- **Sandspiel** uses [Max Bittker’s MIT simulation](https://github.com/MaxBittker/sandspiel/tree/9936e06b07a583aedfba9589c0cead2917f405fb) and the original WebAssembly binary from [the upstream Pages build](https://github.com/MaxBittker/sandspiel/tree/24a63c60428cae13714946118f025d5d1484b344). It has an Uzbek toolbar and uses a local Canvas renderer with keyboard drawing and undo.
- **Rusted Cannon** uses [Cyril Dieumegard’s MIT game and artwork](https://github.com/CyrilDieumegard/rusted-cannon/tree/42f12e0e029137740286fac9c116cd28a08da23b). The Arcade integration uses CSP-compatible script files, exposes the on-screen controls to mouse users and sends the high score to the Arcade player. The original soundtrack credits cover all three CC0 tracks.
- **Sky Isles** uses [Stanislav Sorokin’s MIT game](https://github.com/stas4000/sky-isles/tree/efdc8a8bc1b76a36222a22f5a211fee859fc84f7) and the accompanying Three.js license. The Arcade version has Uzbek prompts, exposes the joystick and jump button to mouse users, and records the longest correct chime sequence.
- **Tidewater** uses [Dan Greenheck’s MIT game](https://github.com/dgreenheck/tidewater/tree/4811ba48d795197de5621985f404e765c0b7c0ef). The graphics, models and audio load from local files. Arcade saves the game and the heaviest catch on the device. The upstream credits and asset notices accompany the build.
- **Sprite Garden** uses [Karl Herrick’s AGPL-3.0 game](https://github.com/kherrick/sprite-garden/tree/76741a5269ecd62158a315762719cca16fd7a123). Arcade loads the game locally, saves worlds and seed records in the browser, and provides the modified source and dependency notices in the in-game About dialog.
